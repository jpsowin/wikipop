Changelog

Major updates and improvements to WikiPop.

April 15, 2026
Email Teasers & Bug Fixes
  • Email Teasers: Added a hidden preheader to daily emails so Gmail displays the obscure article's description as a teaser instead of repeating the subject line.
  • Test Emails: Created a new GitHub Actions workflow to easily send test emails to a specific address without blasting the subscriber list.
  • Duplicate Prevention: Added strict checks to prevent the system from accidentally sending multiple emails for the same article on the same day.
  • iPad Layout: Fixed a CSS float bug that caused text to overlap the comic panel on iPad screens.
  • Image Loading: Added explicit width and height attributes to the hero image to prevent it from squishing while the page loads.
  • Auto-Backfill: The daily GitHub Action now automatically looks back 3 days to catch and backfill any missed Wikipedia data.
  • Relative URLs: Updated all templates to use relative URLs for better compatibility with GitHub Pages.
April 10, 2026
Initial Launch
  • Core Site: Launched the main WikiPop website, featuring the most popular Wikipedia article of the day.
  • Explore & Archive: Added an Explore page to see top 25 lists and biggest movers, plus a full Archive of past entries.
  • Daily Emails: Set up automated daily emails via Buttondown and GitHub Actions to deliver the top article and an obscure entry straight to inboxes.
  • Museum: Added a museum section with interactive toys like the Background Adjuster.
